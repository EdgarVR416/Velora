# Velora Executor Website

A sleek, modern, and user-friendly website for "Velora Executor" featuring an advanced dark theme with smooth animations and transitions.

## Features

- Responsive design that works on desktop and mobile devices
- Modern dark theme with subtle animations and glow effects
- Interactive UI demo that simulates script execution
- Smooth scrolling and navigation
- FAQ section with accordion functionality
- Mobile-friendly navigation with hamburger menu

## Preview

The website showcases the Velora Executor UI (using the image from https://i.imgur.com/OUmNhIG.png) and presents its features in a modern, engaging way.

## How to Run

1. Simply open the `index.html` file in a modern web browser.
2. No server or build process is required - this is a static website built with HTML, CSS, and vanilla JavaScript only.

## Project Structure

- `index.html` - The main HTML structure of the website
- `styles.css` - All styling for the website including responsive design
- `script.js` - JavaScript for interactive elements and animations

## Browser Compatibility

This website is designed to work well in modern browsers including:
- Chrome (recommended)
- Firefox
- Safari
- Edge
